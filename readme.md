## 🎮 What is Sparkiddo?

Sparkiddo is a safe, ad-free kids gaming and learning platform  
with 14 games across 3 zones:

| Zone | Games |
|------|-------|
| 📚 Fun & Learn | Math Dojo · Color & Shape Quest |
| 🏅 Sparkiddo Morals | Emotion Match · Kindness Quest · Story Choices · Share or Keep? · Truth or Fib? · Cool Down Corner · My Daily Dojo · Pet Dojo |
| 🎮 Arcade | Snake · Tic Tac Toe · Memory Match · Rock Paper Scissors |
